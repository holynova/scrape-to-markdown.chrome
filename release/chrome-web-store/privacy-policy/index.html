Scrape to Markdown Privacy Policy

Last updated: July 26, 2026

Overview

Scrape to Markdown is a Chrome side-panel extension that helps you export content from the active browser page or from an AI service session you have already signed into. It offers page-to-Markdown conversion, image downloads, Weibo and Douban exports, and selected ChatGPT conversation exports. These actions begin only when you choose a feature in the extension.

Information the extension processes

Depending on the feature you start, the extension can process readable page content, image URLs and dimensions, Weibo or Douban content visible in your browser, and ChatGPT conversation data, generated images, or attachments you select for export. It processes this information in the browser to create the file you requested.

Storage and retention

The extension uses Chrome local storage for the selected interface language and temporary operational state needed to resume or stop Douban scraping. Exported files are created through Chrome's download manager and are kept according to your browser download settings. The extension has no developer-operated backend and does not retain a copy of your exports outside your browser.

Network connections

When you request an export, the extension may connect to the website or AI service you selected, such as a page's image host, ChatGPT, Gemini, Weibo, or Douban, to retrieve the content required for that export. It does not send exported page content, conversation data, or images to a separate developer-operated service. The extension does not include analytics, advertising, payment processing, or trackers.

Permissions

The extension uses Chrome permissions to show its side panel, access the active tab after you start an action, store local operational state, send user-initiated export commands to page tools, navigate the active tab for the sequential Douban workflow, and save requested downloads. Its host access supports the active-page tools and the specific source integrations described above.

Your choices

You choose which tool to run, which ChatGPT conversations to include, whether to include generated images, and when to download an export. You can clear local extension data by removing the extension or using Chrome's extension site-data controls. You can also remove downloaded exports using your browser or operating system.

Security

Network requests use the HTTPS endpoints supplied by the selected website or service when available. Because exports are created in your browser, you should protect your browser profile and downloaded files using the controls provided by your device and browser.

Policy changes and support

Updates to this policy will be published with changes to the extension. For questions or support, open an issue at the project's GitHub issue tracker.
