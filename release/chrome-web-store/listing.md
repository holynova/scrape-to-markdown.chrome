# Store Listing

## Name

Scrape to Markdown

## Short Description

Save readable web pages as Markdown, export Weibo and Douban data, and download selected web, AI, and ChatGPT conversation content.

## Detailed Description

Scrape to Markdown is a Chrome side-panel tool for exporting content that is visible in the browser tab you choose.

- Convert the readable content of the current page to Markdown.
- Scan a page for images, filter them by size, and download selected images in a ZIP file.
- Download original images from Gemini MyStuff and ChatGPT Images while using the signed-in browser session.
- Export Weibo profile posts and Douban book or movie lists to JSON or Markdown.
- Scan selected ChatGPT conversations and download a ZIP containing JSON, Markdown, HTML, and optional generated images or attachments.
- Switch the side panel between English and Chinese.

The extension performs these actions only after a user starts the corresponding feature. Export files are downloaded through Chrome and remain under the user's browser download settings.

## Single Purpose

Help users export and download content from the active browser page or their signed-in AI service session in portable formats.
